# 🍵 Matcha.exe - Premium Beverage Landing Page

[![Framework: React](https://shields.io)](https://react.dev)
[![Styling: CSS](https://shields.io)](https://mozilla.org)
[![Deployment: Live](https://shields.io)](https://vercel.app)

**Matcha.exe** is a modern, aesthetic, and fully responsive landing page built with React. This project is specifically crafted to showcase a contemporary matcha beverage brand with an appetizing user interface and optimized performance. 

The name **Matcha.exe** was chosen to merge the traditional freshness of matcha green tea with a sleek digital aesthetic, making it highly appealing to the younger generation of tech-savvy consumers.

## ✨ Key Features (UI/UX Highlights)
* **Appetizing Hero Section**: Captures visitors' attention immediately with sharp product visuals, bold typography, and a compelling call-to-action.
* **Interactive Menu Display**: A beautifully organized showcase of matcha drinks (Matcha Latte, Cheese Matcha, Cold Brew Matcha) featuring smooth custom CSS hover effects.
* **Direct Order CTA**: Conversion-focused buttons designed to seamlessly redirect customers to instant delivery and ordering platforms (WhatsApp Business, GoFood, or GrabFood).
* **Mobile-First Responsiveness**: 100% optimized for mobile screens using CSS Flexbox/Grid, ensuring a flawless user experience since most food orders occur on smartphones.
* **Modular React Components**: Built with clean, reusable components (Navbar, Hero, MenuCard, Footer) for scalable and maintainable code.

## 🚀 Getting Started (Local Setup)

1. **Clone this repository**
   ```bash
   git clone https://github.com
   ```
2. **Navigate into the project folder**
   ```bash
   cd matcha-exe
   ```
3. **Install all dependencies**
   ```bash
   npm install
   ```
4. **Run the development server**
   ```bash
   npm run dev
   # Use 'npm start' if you are using Create React App instead of Vite
   ```
5. Open the local address provided in your terminal (e.g., `http://localhost:5173`) in your preferred browser.
